Comparing Browser Security Sandbox vs. Node.js Direct OS Access

1. Frontend (Browser) Sandbox Security

Browsers cannot directly access OS file paths. Users must explicitly upload files, and exports trigger a user download.

A. Read File (Modern file.text()) 
const [file] = inputElement.files;
const text = await file.text(); // Native Promise (No FileReader callback!)

const blob = new Blob([content], { type: "application/json" });
const url = URL.createObjectURL(blob); // Temporary Virtual Link
exportData = { id: 101, status: "Active" }
Security status: Blocked from direct disk write. Downloads require user consent.
2. Backend (Node.js) Direct OS Access

Server scripts have full disk privileges. Modern standard uses node:fs/promises with async/await.

Modern Server Code Pattern 
const fs = require('node:fs/promises');
const path = require('node:path');

// 1. Direct write to physical server disk
await fs.writeFile(filePath, JSON.stringify(data, null, 2));

// 2. Direct read from disk without user prompt
const raw = await fs.readFile(filePath, 'utf8');
const data = JSON.parse(raw);
